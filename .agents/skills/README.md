# Навыки проекта

В этой папке хранятся локальные навыки для работы с `wallet-ledger-service`.
Общие правила проекта находятся в [AGENTS.md](../../AGENTS.md).

Каждый навык размещается в отдельной папке `.agents/skills/<имя>/`
с обязательным файлом `SKILL.md`:

```text
.agents/skills/
└── <имя-навыка>/
    └── SKILL.md
```

В начале `SKILL.md` укажите YAML-поля `name` и `description` между строками `---`.
Имя должно совпадать с именем папки и состоять из строчных латинских букв,
цифр и дефисов. В описании укажите назначение навыка и ситуации, когда он нужен.
После YAML разместите инструкции для выполнения задачи.

Добавляйте папки `scripts/`, `references/` и `assets/` только при необходимости.
Ссылки на вспомогательные материалы и условия их чтения указывайте в `SKILL.md`.
Не дублируйте в навыках общие правила из `AGENTS.md`.
